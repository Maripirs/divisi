# Fixtures

Synthetic MIDI test fixtures for `MIDIParser` (M2), generated by `generate.py`
(requires `pip install mido`).

All three approximate the opening choral entrance of Mozart's Requiem,
K.626 — Introitus ("Requiem aeternam dona eis, Domine... et lux perpetua
luceat eis"), D minor, Adagio, 8 bars, 4 real SATB tracks (named
`Soprano`/`Alto`/`Tenor`/`Bass`).

**Accuracy note:** reconstructed from memory as a harmonically plausible
chorale reduction (correct key, tempo, text underlay, i–iv–V–i / VI–iv–V7–i
shape) — not a verified transcription against the autograph score. Good
enough to exercise the parser's note/track/lyric handling with a real,
recognizable piece; not performance material.

- `requiem-satb-plain.mid` — SATB only, no lyrics, no accompaniment (baseline)
- `requiem-satb-lyrics.mid` — SATB + per-syllable lyric meta-events (0xFF 0x05) on each voice track
- `requiem-satb-accompanied.mid` — SATB + a 5th "Organ" pad track doubling the harmony (tests that non-vocal tracks aren't misidentified as a voice part)
